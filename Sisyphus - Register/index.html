Weekly report scheduler design

This design outlines how weekly student registry reports can be automated outside the browser.

  • Backend endpoint reads the saved student registry.
  • Scheduled job exports the registry to CSV every Monday at 9:00 AM.
  • Email service sends the report to ttyson@blackstudentfund.org.
  • Optional storage: keep a copy in secure cloud storage for audit history.
  • This registry also keeps a weekly student usage log for monitoring action counts and active sessions.
