Simple Search to loops and conditionals

In this project, we will create a simple search function that allows users to search for items in a list. We will use loops and conditionals to implement the search functionality.

Step 1: Create a List of Items

First, we need to create a list of items that we want to search through. For example, we can create a list of fruits:

  • Apple
  • Banana
  • Cherry
  • Date
  • Elderberry

Step 2: Create a Search Function

Next, we will create a search function that takes a search term as input and checks if it exists in the list of items. We will use a loop to iterate through the list and a conditional statement to check for a match.

Step 3: Display the Results

If the search term is found in the list, we will display a message indicating that the item was found. If it is not found, we will display a message indicating that the item was not found.
